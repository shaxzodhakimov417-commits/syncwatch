## 🎬 Как это работает:

### Для лидера:
1. Лидер управляет видео (play/pause/seek)
2. Каждое действие отправляется на сервер
3. Периодически (каждые 2-3 сек) отправляется heartbeat с текущим временем

### Для участников:
1. Получают обновления от сервера в реальном времени
2. **Каждые 10 секунд** проверяют свою позицию
3. Если отклонение >2-5 секунд - автоматически синхронизируются
4. Для VK/RuTube - перезагружают iframe с правильным временем

---

## 📊 Параметры синхронизации:

### YouTube:
- **Drift threshold**: 2 секунды
- **Sync interval**: 2 секунды (heartbeat)
- **Метод**: YouTube IFrame API seekTo()

### VK Video:
- **Drift threshold**: 3 секунды (для reload)
- **Periodic check**: каждые 10 секунд
- **Метод**: Reload iframe с параметром `&t=TIME`

### RuTube:
- **Drift threshold**: 3 секунды (для reload)
- **Periodic check**: каждые 10 секунд
- **Метод**: Reload iframe с параметром `&t=TIME`

## 🎯 Сценарии использования:

### Сценарий 1: Лидер перематывает видео
1. Лидер перематывает на 20:00
2. Сервер получает обновление
3. Участники получают событие `playback-changed`
4. Участники перематываются на 20:00 (±2 сек)

### Сценарий 2: Участник отстал
1. Участник на 19:50, лидер на 20:00
2. Через 10 секунд periodic check обнаруживает drift
3. Участник автоматически перематывается на 20:10 (текущее время лидера)

### Сценарий 3: Лидер ставит с начала
1. Лидер нажимает кнопку "0:00" (Reset)
2. Сервер получает `currentTime: 0`
3. Участники получают обновление
4. Все перематываются на 0:00

### Сценарий 4: Новый участник присоединяется
1. Лидер на 20:00, видео играет
2. Новый участник присоединяется
3. Вычисляется elapsed time с момента последнего обновления
4. Участник загружает видео с правильного времени (20:00 + elapsed)

## 💡 Советы для лучшей синхронизации:

### Для лидера:
1. **Не перематывайте слишком часто** - дайте участникам время загрузиться
2. **Используйте кнопки быстрой перемотки** (-10с, +10с, -1м, +1м)
3. **Подождите 2-3 секунды** после перемотки перед следующим действием

### Для участников:
1. **Не пытайтесь управлять видео** - только лидер может
2. **Если видео отстаёт** - подождите 10 секунд, автоматически синхронизируется
3. **Если не синхронизируется** - обновите страницу (F5)

### Для всех:
1. **Стабильный интернет** - минимум 2 Mbps
2. **Закройте другие вкладки** - освободите ресурсы
3. **Используйте Chrome** - лучшая поддержка WebSocket и IFrame API

## 🐛 Troubleshooting:

### Проблема: Видео не синхронизируется

**Решение 1: Проверьте консоль**
- Откройте F12 → Console
- Посмотрите на логи синхронизации
- Если нет логов - WebSocket не подключен

**Решение 2: Проверьте drift**
- Если drift >10 секунд - обновите страницу
- Если drift <5 секунд - подождите 10 секунд

**Решение 3: Для VK Video**
- VK может блокировать iframe reload
- Попробуйте использовать код iframe с hash
- Или используйте YouTube/RuTube

### Проблема: Участник постоянно отстаёт

**Причины:**
1. Медленный интернет - видео не успевает загружаться
2. Слабое устройство - браузер тормозит
3. VK Video блокирует автоматическую перемотку

**Решение:**
1. Уменьшите качество видео (если возможно)
2. Закройте другие приложения
3. Попробуйте другой браузер
4. Используйте YouTube вместо VK

### Проблема: Лидер не может перемотать

**Решение:**
1. Проверьте что вы действительно лидер (корона рядом с именем)
2. Для VK/RuTube используйте ползунок времени или кнопки
3. Подождите 2-3 секунды после перемотки
